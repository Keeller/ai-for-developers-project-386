# Запись на звонок

Контекст сервиса, в котором человек выбирает доступное время для разговора с владельцем календаря.

## Язык

**Гость**:
Человек, который хочет записаться на звонок через публичную часть сервиса.
_Избегать_: Клиент, посетитель, пользователь

**Звонок**:
Запланированный 30-минутный разговор Гостя с владельцем календаря.
_Избегать_: Встреча

**Запись на звонок**:
Процесс, в котором Гость выбирает доступное время и подтверждает Звонок.
_Избегать_: Бронирование встречи
